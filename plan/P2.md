# P2: Intel oneTBB Thread Scheduling Replacement

**Replace the hand-rolled `std::jthread` pool in `solve_all_boards_n()` with
Intel oneTBB's `tbb::task_arena` + `tbb::parallel_for`. TBB's adaptive work-stealing
scheduler handles load imbalance better than a fixed atomic counter when board
solve times vary widely. Only `solve_board.cpp`, `MODULE.bazel`, and `BUILD.bazel`
files are modified.**

## Steps

Check Bazel Central Registry for current oneTBB version:
  https://registry.bazel.build/modules/onetbb

Add to `MODULE.bazel` after the existing `bazel_dep` lines:


### Step 4 — Modify solve_board.cpp  (depends on steps 1-3)

**4a. Add include** (after the existing `<thread>` include):
```cpp
#include <tbb/task_arena.h>
#include <tbb/parallel_for.h>
```

**4b. Remove the old threading block** — the section that is currently:
```cpp
std::atomic<int> next_board{0};
std::atomic<int> first_error{0};

auto worker = [&] {
  for (;;) {
    const int bno = next_board.fetch_add(1, std::memory_order_relaxed);
    ...
  }
};

START_BLOCK_TIMER;
{
  std::vector<std::jthread> threads;
  threads.reserve(static_cast<unsigned>(nthreads));
  for (int i = 0; i < nthreads; ++i)
    threads.emplace_back(worker);
}
END_BLOCK_TIMER;
```

**4c. Replace with TBB block**:
```cpp
std::atomic<int> first_error{0};

START_BLOCK_TIMER;
{
  tbb::task_arena arena(nthreads);
  arena.execute([&] {
    tbb::parallel_for(
      tbb::blocked_range<int>(0, n),
      [&](const tbb::blocked_range<int>& range) {
        for (int bno = range.begin(); bno != range.end(); ++bno) {
          if (first_error.load(std::memory_order_relaxed) != 0)
            return;

          FutureTricks fut;
          const auto t0 = std::chrono::steady_clock::now();
          const int res = SolveBoard(
            bds.deals[bno], bds.target[bno], bds.solutions[bno],
            bds.mode[bno], &fut, 0);
          const auto dur = std::chrono::duration_cast<std::chrono::milliseconds>(
            std::chrono::steady_clock::now() - t0).count();
          scheduler.SetBoardTime(bno, static_cast<int>(std::max(0LL, dur)));

          if (res == 1)
            solved.solved_board[bno] = fut;
          else {
            int expected = 0;
            first_error.compare_exchange_strong(
              expected, res, std::memory_order_relaxed);
          }
        }
      });
  });
}
END_BLOCK_TIMER;
```

**4d. Remove unused include** `<thread>` if it is no longer needed elsewhere in the file.

## Decisions

- `Scheduler::RegisterRun()` and `scheduler.SetBoardTime()` calls are **preserved**;
  only the thread-pool mechanism is replaced, not the scheduling logic
- The `first_error` early-exit is kept; TBB's `parallel_for` does not support
  clean cancellation, so we use the atomic flag pattern inside the body
- `START_BLOCK_TIMER` / `END_BLOCK_TIMER` macros wrap the TBB block identically
  to preserve timing instrumentation
- If oneTBB is absent from BCR, use `http_archive` pointing to the official
  GitHub release of `oneTBB v2021.13.0`:
    https://github.com/oneapi-src/oneTBB/archive/refs/tags/v2021.13.0.tar.gz
  and add a manual `BUILD.bazel` wrapper for `cc_library(name = "tbb", ...)`

## Further Considerations

1. **oneTBB BCR availability**: Run `bazel mod show onetbb` to check. If not found,
   fall back to `http_archive` — the implementation plan remains identical.
2. **Grain size tuning**: `tbb::blocked_range<int>(0, n, /*grain=*/1)` ensures each
   board is treated as an independent task (grain=1 is TBB default for small n).
   For very large batch sizes (n > 200), consider grain=4 to reduce scheduling overhead.
3. **Thread count cap**: `tbb::task_arena(nthreads)` respects the same
   `min(hardware_concurrency, n)` cap already computed before the TBB block.
