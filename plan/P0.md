# P0: Performance Baseline Establishment

**No source code changes. Build the optimized binary, run benchmarks, record metrics.**

## Steps

1. Build optimized binary:
   `bazel build -c opt //library/tests:dtest`

2. Record machine info in `perf/baseline_env.txt` (new file, not in Bazel):
   CPU model, core count, base/boost clock, RAM, OS, toolchain version

3. Run single-thread baseline:
   ```
   bazel-bin/library/tests/dtest.exe -f hands/list100.txt  -s solve -n 1
   bazel-bin/library/tests/dtest.exe -f hands/list1000.txt -s solve -n 1
   ```

4. Run multi-thread baseline (parallel with step 3 mentally — same binary):
   ```
   bazel-bin/library/tests/dtest.exe -f hands/list100.txt  -s solve -n 2
   bazel-bin/library/tests/dtest.exe -f hands/list100.txt  -s solve -n 4
   bazel-bin/library/tests/dtest.exe -f hands/list100.txt  -s solve -n 8
   bazel-bin/library/tests/dtest.exe -f hands/list1000.txt -s solve -n 4
   bazel-bin/library/tests/dtest.exe -f hands/list1000.txt -s solve -n 8
   ```

5. Confirm all tests pass:
   `bazel test //...`

6. Save timing data to `perf/baseline.md` in a table:
   | hands | threads | time_ms | notes           |
   |-------|---------|---------|------------------|
   | 100   | 1       | ?       | clang baseline  |
   | 100   | 4       | ?       | clang baseline  |
   | ...   | ...     | ...     | ...             |

## Relevant Files
- `library/tests/dtest` target (no changes)
- `hands/list100.txt`, `hands/list1000.txt` — benchmark inputs
- `library/tests/TestTimer.hpp` — confirms timing output format
- `perf/baseline_env.txt` — NEW, machine info
- `perf/baseline.md` — NEW, timing table

## Verification
1. `bazel test //...` → 0 failures
2. `perf/baseline.md` table fully populated
3. `perf/baseline_env.txt` contains CPU/core/toolchain info

## Decisions
- Zero code changes in this phase
- VTune optional: `vtune -collect hotspots -- dtest.exe -f hands/list1000.txt -s solve -n 4`
- `perf/` is a manual directory, not a Bazel target
